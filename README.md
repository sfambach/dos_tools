# dos_tools

A collection of small DOS tools for the IBM PC/XT/AT and compatibles.

| Tool | Purpose |
|---|---|
| [lfndel](lfndel/) | Lists or removes long file names (VFAT LFN entries) on FAT12/16 under DOS 3.x |
| [graphic_mode_tester](graphic_mode_tester/) | Steps through all video modes of the graphics card (MDA, CGA, EGA) and shows a static test image in each |
